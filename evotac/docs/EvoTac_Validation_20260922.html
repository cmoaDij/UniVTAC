快速验证路线

  1. 用真实 Isaac/TacEx 采集 500–2000 条恢复转移；保留终止原因和真实 continuation reward。
  2. 用训练集统计触发分数，比较阈值 0.25、0.30、0.35 和恢复上限 6、12、20，选择正例率与预算消耗的平衡点。
  3. 冻结阈值、恢复预算和 checkpoint，禁止 test 在线更新。
  4. 严格快照只有在机器人、相机、触觉和连续 rollout 都通过审计后才进入因果比较。
