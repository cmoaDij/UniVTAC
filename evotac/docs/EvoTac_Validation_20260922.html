失败线索与当前决策

  • 触发覆盖和时机存在问题：seed 18 四组均超时，恢复组未触发；seed 0 的训练后组仅剩 18 个物理步（3 个控制步）才触发，随后在恢复中丢失物体。
  • seed 59 成功基线的最高图像风险代理为 0.299802，略低于阈值 0.3；训练后失败运行在 0.302156 触发，当时仅剩 168 个物理步。这提示阈值附近敏感性，需要另行验证，尚不能认定为唯一失败原因。
  • seed 39/86 的训练前恢复成功、训练后恢复失败。训练后组 seed 86 在 3 个“稳定”恢复动作后交接，又执行 23 个基策略动作才丢失物体；图像稳定不等于恢复任务完成。SAC 政策质量、交接条件和基策略续接均需检查。
  • 训练只有 27/641 条正奖励转移（4.21%），稀疏反馈或遗忘是候选解释，尚未通过消融证明。不能仅凭 626 次更新把该版本称为有效进化。

开发决策：不将当前训练后 checkpoint 作为已验证改进推进到正式 test。 原 checkpoint 和全部证据保留；下一轮应先在 train 内处理稀疏奖励/示范保持，在 dev 单独验证触发预算和交接，再冻结新的候选评估协议。不能持续调参直到出现有利 dev 数字后宣称成功。本轮不是完整 P5 适应接纳实验，也不解除严格快照审计门禁。
